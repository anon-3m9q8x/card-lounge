# Card Lounge — 7ゲーム対応

深緑のフェルト卓、チャコールとゴールド、紙のトランプを基調とした日本語カードゲームサイトです。AWS学習サイトとは独立した新規プロジェクトです。

## 起動

Node.js 22.12以降または24系を推奨（Vite7の要件を満たすバージョン）。今回の実行環境はNode24.22.1。

```sh
cd /workspace/card-lounge
npm ci
npm run dev -- --port 3400
```

```sh
npm test
npm run build
npm run preview -- --port 3401
```

ビルド成果物はdist/。GitHub Pagesを想定した相対baseとハッシュURL（#/play/memory等）です。file://による直接オープンは対応しません。ソースはmainブランチで管理します。GitHub Actionsはmainの更新時にnpm ci・npm test・npm run buildを実行し、dist/をGitHub Pagesへ配信します。

## 遊べる7ゲーム

- **ソリティア**：クロンダイク・ドロー1、山札再循環無制限。表向きの束移動、組札と列の相互移動、自動めくり、10手までのUndo、見えている合法手のヒント。4組札がA〜Kで完成。
- **神経衰弱**：8/12/26ペア、1人/CPU対戦。同ランク・同色のペア。初級2枚・中級6枚・上級は観測済みの全未一致札を記憶。
- **ババ抜き**：人間1人＋CPU3人、ジョーカー1枚の53枚。同ランクのペアを自動除去、隣の有効な相手から1枚選ぶ。CPUは裏札の位置をランダム選択。最後のジョーカー保持者が敗者。
- **七並べ**：人間1人＋CPU3人。4スートの7から連続する数字を置く。合法手ありの自発パス3回、合法手なしの強制パスは別計数。CPU3難易度、全員のあがり順を記録。
- **スピード**：人間対CPU、中央2枚に±1、A/Kも隣接。公開札4枚＋補充山、双方手詰まり時に中央更新。3難易度。先に空にした側が勝利、補充不可の手詰まりは残数比較・同数引き分け。再開時は3→2→1。
- **大富豪**：人間1人＋CPU3人、ジョーカー1枚の53枚。♦3を持つ人から開始。強さは3＜…＜K＜A＜2＜ジョーカー。1枚または同じ数字の2〜4枚(ジョーカー代用可)を、場と同じ枚数でより強く出す。パスした人は場が流れるまで出せない。8切り・革命(4枚出し)あり。階段・縛り・都落ち・カード交換はなし。あがり順に大富豪〜大貧民、大富豪で勝利。CPU3難易度。
- **UNO**：人間1人＋CPU3人、108枚・7枚配り。色か数字・記号を合わせて出す。スキップ・リバース・ドロー2・ワイルド・ワイルドドロー4。出せない/出さないときは1枚引き、引いた札は出すかパス。重ね出し・チャレンジ・UNO宣言忘れの罰はなし。最初にあがった人の勝ち。CPU3難易度。

## 操作

ホームのゲームカードから開始。ソリティアは移動元カードを選択してから「列に置く」「組札に置く」を押します。途中のカードを選ぶと、そのカード以下の束を移動。ババ抜きは相手の裏札から1枚選択、七並べは自分の出せる札を選択します。大富豪は手札を選んで「選んだ札を出す」かパス。UNOは光っている札を押して出し(ワイルドは続けて色を選択)、出せないときは山札を押して1枚引きます。スピードは自分の公開札→左か右の中央札の順に選択。すべてボタンで操作でき、ドラッグは不要です。

小画面のソリティア・七並べは卓内のみ横スクロールできます。ページ全体を横にスクロールする必要はありません。

## 共通機能

ゲームごとに1件ずつ中断保存。既存の神経衰弱の保存・戦績・設定は維持します。一時停止、保存して終了/保存せず終了/キャンセル、タブ非表示時の停止、重複しない結果記録に対応。CPUは自分の札・公開情報のみを利用し、ババ抜きでは相手の札の枚数だけから引く位置を選びます。

ローカル戦績と同設定・補助なしの上位10件。ソロは時間順、神経衰弱CPU戦は獲得ペア数順、七並べは先着順位順。ババ抜きはタイム順位を付けず、補助なしの現在/最高連勝・通算勝利を表示。ヒント/Undo使用は記録に明示し、通常ランキングから分離します。

卓3種、裏面3種、dark/light/system、動き軽減。外部API・DB・認証・課金・賭け金・オンライン対戦はありません。

## 未実装・未確認

効果音、実績・称号、戦績消去、仕様書の全111項目の完了判定は対象外です。5ゲームの開始・操作・終局・保存と結果を検証していますが、すべてのランダム局面の勝利や全ブラウザでの完全な動作を保証するものではありません。

## 保存

localStorageのcard-lounge:v1を使用します。保存形式v1を拡張し、ゲームごとのセッションを保持します。従来の神経衰弱データは移行操作なしで読み込み、既存フィールドと保存キーを保持します。破損・将来版・未知のゲーム保存は上書きせず一時プレイへ切り替えます。保存容量不足は通知し、プレイを継続。別タブの変更検出後はこのタブからの書き込みを停止。

再開用データにはカード配置が含まれますが、裏向きカードの中身はDOM/aria-labelへ出しません。端末内ゲームでありサーバーによる不正防止・端末間同期・オンライン対戦はありません。

## 構成

- src/App.tsx: ホーム・ゲーム画面・結果・戦績・設定・スケジューラー
- src/app/types.ts: 今回実装した型
- src/core/cards.ts: カード生成・再現可能な乱数・シャッフル
- src/core/storage.ts: 保存検証・保護・記録・ランキング
- src/games/registry.ts: 5ゲームの案内・ルールと実装状態
- src/games/memory/engine.ts: 神経衰弱の状態遷移・CPU観測/選択
- src/games/engine.ts: 全ゲームの操作/時計/保存の共通窓口
- src/games/table/: 卓ゲーム(ソリティア・ババ抜き・七並べ・スピード・大富豪・UNO)の型・ルール・CPU・保存検証・画面・ランキング。大富豪は daifugo.ts / DaifugoView.tsx、UNOは uno.ts / UnoView.tsx
- src/components/: カード描画・ダイアログ
- src/styles/global.css: フェルト・カード・レスポンシブ・テーマ
- tests/memory.test.ts / table.test.ts / daifugo-uno.test.ts: Node組み込みランナーによる単体テスト
- tests/fixtures.ts: 検証専用の正当な終局直前局面（アプリにはバンドルされません）
- tests/five-games-browser.py: 追加4ゲームの画面操作・終局・保存復元の検証
- tests/browser.py: Playwright / /usr/bin/chromiumがある環境でのブラウザ確認
- docs/: 元仕様書（参考資料）・スコープ・実行結果・画面

## 外部依存

実行時はReact/React DOMのみ。開発用はVite/TypeScript/公式型。外部画像・フォント・API・認証・DBなし。追加の状態管理/ルーター/ゲーム/アニメーションライブラリなし。ブラウザ検証のみPython Playwrightを利用します。

本番ビルドをプレビュー起動後の検証例：

```sh
CARD_LOUNGE_BASE_URL=http://127.0.0.1:3401 python3 tests/browser.py
CARD_LOUNGE_BASE_URL=http://127.0.0.1:3401 python3 tests/five-games-browser.py
```

最新の変更と検証はdocs/FIVE_GAMES_REPORT.mdを参照してください。docs/TEST_REPORT.mdとSTEP1_SCOPE.mdは最初の基本版の履歴です。
