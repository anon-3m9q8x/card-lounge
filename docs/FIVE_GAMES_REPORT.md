# 5ゲーム対応の実装・検証記録

## 追加したゲーム

- クロンダイク: ドロー1/再循環無制限、7列、4組札、見えている束の合法移動、列の自動めくり、組札から列への戻し、10手までUndo、合法手のヒント、52枚完成判定。
- ババ抜き: 人間1+CPU3、53枚、同ランクのペア除去、空手札のスキップ、時計回りの相手から裏札位置を選択、最後のジョーカー保持者が敗者。CPUは対象の札の枚数だけから均等な位置抽選。
- 七並べ: 全7を中央へ配置、♦7所持者の次の席から開始、連続ランクの配置、自発パス3回/強制パス別計数、3難易度、全員のあがり順・人間の順位。
- スピード: 中央2枚/公開札4枚/補充21枚、A-K隣接、更新後の盤面で原子的に合法性再判定、双方手詰まり時の中央更新、片側補充、補充なし時の残数比較・引き分け、3難易度。専用時計でCPUを動かし、人間の操作で予約を先延ばししない。再開時はpausedを維持して3→2→1。

## 共通機能と互換性

5ゲームを型安全な共通操作・時計・保存口へ接続。神経衰弱のモデルと判定器は保持。保存キーとschemaVersion1を維持し、savesに各ゲームの独立スロットを追加。レコードはgameId/configで区別し、完了時のみ1件を記録。同sessionIdの再処理は増加しない。旧神経衰弱の保存、戦績、processedSessionIdsを残した5スロット共存をテスト。

ゲームごとの局面を検証し、52/53枚の重複・消失、無効ランク、列の順序、配置済み札と手札の重複、不正な着順などを拒否。破損・対応外データは上書きしない。終了後はそのゲームのスロットだけを削除。

ローカルランキングは同ゲーム・同設定・補助なしに限定。ババ抜きはタイム順位でなく連勝・通算勝利。ヒント/Undo使用は戦績に明示。ソリティアの完成枚数以外に架空の得点は付けず、勝敗ゲームのscoreはnull。
