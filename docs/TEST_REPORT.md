## 修正したもの

- 初回インストールを親ディレクトリで実行したため失敗。作成した空の親lockfileを確認して削除し、プロジェクト内で再実行。
- 初回型チェックでMemoryConfigのimport不足を検出し修正。
- ブラウザ検証の再開ボタン選択を矢印込みラベルに対応。
- カード裏面プレビューの装飾記号をaria-hiddenにし、モード/ペア数/CPU難易度selectのアクセシブル名を明示。
- 別タブ競合時にpause処理より先に書き込み保護するよう修正。
